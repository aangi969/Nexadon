# Nexadon

Nexadon — Next-Generation Web3 Crypto & Gaming Ecosystem.

## Features
- **Modern Responsive Design**: Fully optimized for mobile, tablet, and desktop viewports.
- **Interactive Carousels**: Fluid horizontal swipeable carousels for Live Features and the Target Referral Program.
- **Interactive Calculators**: Dynamic tokenomics metrics and referral reward estimators.
- **Cyber-Luxury Aesthetics**: Glassmorphism, neon laser borders, glowing scrollbars, and smooth micro-animations.

## Getting Started
Open `index.html` in any modern web browser or deploy to any static hosting provider (e.g., GitHub Pages, Vercel, Netlify).
